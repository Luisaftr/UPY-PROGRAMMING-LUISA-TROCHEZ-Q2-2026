1. COUNTDOWN

INPUT
- Get n as an integer.

PROCESS
- Start the recursive function countdown with n.
- Check if n is an integer.
- If n is not an integer:
    - Display an error message.
    - Return no value.
- Check if n is negative.
- If n is negative:
    - Display an error message.
    - Return no value.
- If n is equal to 0:
    - Return "Done!"
- Otherwise:
    - Display n.
    - Call the countdown function again using n - 1.

OUTPUT
- Display every number from n down to 1.
- Return "Done!" when n reaches 0.
- Display an error message when the input is invalid.

START
- Call countdown with the desired value of n.
END

- Call recursive integer division with the desired dividend and divisor.

        - Display the result.
        - Call the Collatz function again using the result.

OUTPUT
- Display every value generated by the Collatz sequence.

- Display an error message when the input is invalid.

START
- Call the Collatz function with the desired value of n.
END

8. FLATTEN A NESTED JSON DICTIONARY

INPUT
- Get dictionary as a dictionary.
- Get parent key as text, initially empty.
- Get separator as text, initially ".".

PROCESS
- Start the recursive flatten JSON function.
- Check if dictionary is a valid dictionary.
- If it is not a dictionary:
    - Display an error message.
    - Return an empty dictionary.
- Create an empty list called elements.
- For every key and value in the dictionary:
    - If parent key is empty:
        - Use the current key as the new key.
    - Otherwise:
        - Join parent key, separator, and current key to create the new key.
    - Check if the current value is another dictionary.
    - If the value is a dictionary:
        - Call the flatten JSON function again using:
            - The nested dictionary.
            - The new key as the parent key.
            - The same separator.
        - Add all returned key-value pairs to elements.
    - Otherwise:
        - Add the new key and its value to elements.
- Convert elements into a dictionary.
- Return the flattened dictionary.

OUTPUT
- Return one dictionary containing flattened keys.
- Nested keys are joined using the separator.
- Display an error message and return an empty dictionary when the input is invalid.

START
- Call the flatten JSON function with the desired nested dictionary.
END
